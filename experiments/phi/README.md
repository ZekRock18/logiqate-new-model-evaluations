# Phi-4 via Ollama — available Tier-1 methods

This folder contains the three methods currently available for this local Phi-4 run. Each method folder has a notebook, a shared benchmark CSV, row-level results, and a summary CSV:

1. [Normalize then solve](01_normalize_then_solve/)
2. [Structured decomposition](02_structured_decomposition/)
3. [Explicit task instructions](03_explicit_task_instructions/)

The source filenames identify a Phi-4 Ollama 250-question run. The remaining four Tier-1 methods and the three assigned prompting experiments are not present here. For any reported accuracy, check the matching summary CSV's denominator and variant before comparing it with another model.
