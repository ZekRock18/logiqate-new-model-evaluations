# Llama 3.1 via Ollama — available Tier-1 methods

This folder contains the three methods currently available for this local Llama run. Each method folder has a notebook, a shared benchmark CSV, row-level results, and a summary CSV:

1. [Normalize then solve](01_normalize_then_solve/)
2. [Structured decomposition](02_structured_decomposition/)
3. [Explicit task instructions](03_explicit_task_instructions/)

The source filenames identify a Llama 3.1 Ollama 250-question run. These files are kept in their original result format; this directory does not claim the remaining four Tier-1 methods or the three assigned few-shot/analogy experiments were run for Llama. Start with a method's summary CSV for its per-dataset counts, then inspect the notebook and result CSV for how it was produced.
