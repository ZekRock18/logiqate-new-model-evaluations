# Seven Tier 1 Prompting Methods

These seven methods were evaluated in addition to the three supervisor-assigned experiments. Each method was applied only to its documented task matrix, while methods claiming clean-performance preservation were also evaluated on the corresponding base forms.

1. [Normalize Then Solve](01_normalize_then_solve/)
2. [Structured Decomposition](02_structured_decomposition/)
3. [Explicit Task Instructions](03_explicit_task_instructions/)
4. [Chain of Thought](04_chain_of_thought/)
5. [Re-reading / System 2 Attention](05_rereading_s2a/)
6. [Self-Consistency](06_self_consistency/)
7. [Self-Verification / CoVe](07_self_verification_cove/)

The methods cover different task subsets, so compare task/variant cells against their matched zero-shot controls rather than comparing each method's overall micro-accuracy directly.
