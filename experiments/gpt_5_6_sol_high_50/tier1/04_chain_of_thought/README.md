# Chain of thought

The prompt requests intermediate reasoning before a final answer. This is a Tier-1 method in the GPT-5.6 Sol (high) 50-question study.

On the applicable obfuscated questions it answered 176/250 (70.4%) correctly. Method sample sizes differ, so compare it with the matched zero-shot cells in the [analysis tables](../Analysis/improvement_over_control.csv), not with another method's raw percentage.
