# Obfuscated-to-obfuscated few-shot

Two worked obfuscated examples precede each obfuscated test question. This is one of three assigned mitigation experiments on the same 250 obfuscated targets for GPT-5.6 Sol (high).

The model answered 150/250 (60.0%) correctly; its fresh matched zero-shot control answered 163/250 (65.2%). Treat this as a descriptive comparison, not an independently replicated effect.
